# Dev Server

Start the development server for the MATE Token web app.

## Usage
Run from `/web` directory:
```bash
pnpm run dev
```

The server starts at http://localhost:4321 with hot module replacement.

## Notes
- Uses Astro with React, Vue, and Solid integrations
- Tailwind CSS v4 for styling
- Three.js / R3F for 3D graphics
- SSR mode enabled with Node adapter
